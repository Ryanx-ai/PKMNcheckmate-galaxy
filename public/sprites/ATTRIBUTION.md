# Sprite attribution

76 Pokémon sprites downloaded from the [PokéAPI sprites repository](https://github.com/PokeAPI/sprites), `sprites/pokemon/{national-dex-id}.png`, on 2026-09-11. The repository documents this distribution format in its README. Regenerate the selected assets with `npx tsx scripts/fetch-sprites.ts`.

Pokémon characters and original game artwork belong to Nintendo, Game Freak and The Pokémon Company. Community-contributed sprites are credited through the upstream repository and its contributor records. This is an unofficial, noncommercial fan prototype; the code does not assert ownership of the artwork or Pokémon trademarks. No generated image assets or runtime PokéAPI calls are required.

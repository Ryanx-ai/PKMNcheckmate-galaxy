# Pokémon Checkmate · Galaxy

A browser Pokémon auto-battler built from scratch. See [the resolved V1 spec](docs/V1-SPEC.md) for scope, rules and decisions, and [recovered planning](docs/RECOVERED-PLANNING.md) for source context.

```sh
npm install
npm run dev
```

Checkpoints are saved on `codex/v1-foundation`. Development is in progress; implementation and validation details will be recorded at each milestone.
